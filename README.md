# 🌍 我们的旅行地图

一个简单而美丽的网页应用，用于记录你和你的伴侣一起去过的地方以及未来想去的地方。

## ✨ 功能特点

- 🔒 **访问控制**：密码保护，只有你们两个人可以使用
- 👥 **双用户系统**：支持两个用户，各自记录自己的旅行足迹
- 🖼️ **自定义头像**：每个用户可以上传自己的头像，在地图上清晰区分
- 🗺️ **交互式地图**：使用 OpenStreetMap 显示世界地图
- 📍 **智能标记**：地图标记显示用户头像，一目了然谁去过哪里
- 🔍 **搜索坐标**：输入城市名称自动获取坐标，无需手动查找
- 📝 **备注功能**：为每个地点添加详细的备注和回忆
- 📅 **日期记录**：记录访问日期或计划日期
- 🔍 **筛选功能**：可以筛选查看已去过、想去或按用户筛选
- 💾 **本地存储**：数据保存在浏览器本地，无需服务器
- 📱 **响应式设计**：支持手机、平板和电脑访问

## 🚀 使用方法

### 首次使用

1. **设置访问密码**：
   - 打开 `index.html` 文件
   - 首次使用会要求设置访问密码
   - 输入密码后，这个密码将用于后续访问（请记住这个密码！）

2. **设置用户信息**：
   - 进入应用后，点击右上角"⚙️ 设置"按钮
   - 为两个用户分别设置名称和上传头像
   - 建议使用真实的照片作为头像，这样在地图上更容易区分

### 日常使用

1. **切换用户**：
   - 点击右上角的"切换"按钮可以在两个用户之间切换
   - 当前用户会显示在顶部

2. **添加地点**：
   - 点击"添加地点"按钮
   - 选择是"用户1"还是"用户2"添加的地点
   - 填写地点信息：
     - 地点名称（必填）- 输入城市名称后点击"搜索坐标"自动获取位置
     - 类型：选择"已去过"或"想去"
     - 备注：记录你们的回忆或计划
     - 日期：访问日期或计划日期
     - 坐标：自动填充（搜索后）或手动输入/在地图上点击

### 操作指南

- **添加地点**：点击右上角"添加地点"按钮，选择用户后填写信息
- **查看详情**：点击地图上的标记或侧边栏的地点卡片
- **编辑地点**：在详情页面点击"编辑"按钮
- **删除地点**：在编辑模式下点击"删除"按钮
- **筛选地点**：使用顶部的筛选按钮
  - **全部**：显示所有地点
  - **已去过**：只显示已去过的地方
  - **想去**：只显示想去的地方
  - **按用户**：只显示当前用户添加的地点
- **定位地点**：在详情页面点击"定位"按钮，地图会跳转到该位置
- **切换用户**：点击右上角"切换"按钮切换当前用户
- **用户设置**：点击"⚙️ 设置"修改用户名称和头像
- **导出数据**：点击"📤 导出数据"导出所有地点记录（用于分享给对方）
- **导入数据**：点击"📥 导入数据"导入对方发送的数据文件（合并数据）

### 获取坐标的方法

1. **搜索城市名称**（推荐）：输入城市名称（如：北京、Paris、Tokyo），点击"搜索坐标"按钮自动获取
2. **在地图上点击**：打开添加地点对话框后，直接在地图上点击即可自动填入坐标
3. **使用当前位置**：点击"当前位置"按钮（需要浏览器允许位置权限）
4. **手动输入**：在Google地图或其他地图服务上找到地点的经纬度，手动输入

## 💾 数据存储和共享

### 数据存储方式

所有数据都保存在浏览器的 `localStorage` 中，包括：
- `travelMapPassword`：访问密码
- `travelMapUsers`：用户信息（名称和头像）
- `travelPlaces`：所有地点记录

**这意味着：**
- ✅ 数据只保存在各自的浏览器中，隐私安全
- ✅ 不需要服务器，可以离线使用
- ⚠️ 清除浏览器数据会删除所有记录（建议定期备份）
- ⚠️ **默认情况下，不同浏览器/设备之间的数据不会自动同步**

### 🔄 如何共享数据（互相查看对方添加的地点）

由于数据保存在各自的浏览器中，**她添加的地点，你默认看不到**。但可以通过以下方式共享：

**方法：导出/导入数据**

1. **她导出数据**：
   - 她添加完地点后，点击右上角"📤 导出数据"按钮
   - 会下载一个 JSON 文件（包含所有地点和用户信息）
   - 将这个文件发送给你

2. **你导入数据**：
   - 收到文件后，点击右上角"📥 导入数据"按钮
   - 选择她发送的 JSON 文件
   - 系统会自动合并数据（不会覆盖你已有的地点）
   - 现在你就能看到她添加的所有地点了！

3. **你也可以导出给她**：
   - 同样操作，你导出数据发送给她
   - 她导入后就能看到你添加的地点

**提示：**
- 导入会智能合并数据，不会覆盖已有的地点
- 如果同一个地点被两人都添加了，会保留最新的版本
- 建议定期互相导出/导入，保持数据同步

### 数据备份和恢复

**方法一：使用导出功能（推荐）**
- 点击"📤 导出数据"按钮
- 会下载包含所有数据的 JSON 文件
- 需要恢复时，使用"📥 导入数据"功能

**方法二：手动备份**
如果需要手动备份，可以：
1. 打开浏览器开发者工具（F12）
2. 进入 Application/存储 → Local Storage
3. 复制以下键的值：
   - `travelMapPassword`（密码）
   - `travelMapUsers`（用户信息）
   - `travelPlaces`（地点数据）
4. 保存为文本文件备份
